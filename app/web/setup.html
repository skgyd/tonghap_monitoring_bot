1. 기존 Mattermost 연결

봇은 각 채널의 멤버여야 합니다. 표시명이 관제라면 연결 검사 때 관제팀으로 변경합니다. 이름 변경 권한이 없으면 관리자에게 먼저 요청하세요.

2. 실제 화면에서 읽을 칸 지정

프로그램 전용 브라우저 창에서 실제 URL을 열고 로그인하세요. 아래 선택 버튼을 누른 뒤 그 창의 해당 데이터 칸을 클릭합니다. 아이디/비밀번호 입력 화면을 선택하지 마세요.

식별자는 발생 ID/실행 ID처럼 재실행 때 달라지는 값이어야 합니다. 행 번호, 지속 시간, 업무명만으로는 중복과 재실행을 구분할 수 없습니다. 화면에 값이 없으면 고급 설정의 DOM 속성 또는 복합 키를 지정해야 합니다. 캔버스/이미지 표는 현재 DOM 방식으로 읽을 수 없습니다.

3. 확인 후 감시 시작

잡패스는 오류 행을 더블클릭해서 열린 팝업의 전체 영역과 같은 실행 식별자, 닫기 버튼을 지정하세요. 로그인 만료나 선택자 불일치는 수집 오류로 표시하며 잘못된 팝업을 보내지 않습니다.

처음에는 예시 오류 1건을 실제 업무 채널에 전달하고 접수·완료 버튼과 관제팀 반영을 확인하세요. 서버 → PC 콜백 포트 연결은 서버/방화벽 설정이 필요할 수 있습니다.

고급 설정 — 자동 생성된 선택자·인증서·구간·포트 수정

편집 후 '고급 내용 적용'을 누른 다음 저장하세요. 실제 표가 iframe 안에 있으면 iframe 선택자도 지정합니다. 페이지 나눔/스크롤은 실제 DOM에 맞게 추가 설정해야 합니다.

감시 중에는 이 프로그램의 콘솔 창을 닫지 마세요. 데이터는 %LOCALAPPDATA%\IncidentBridge에 저장됩니다. 일반적으로 Python·Docker·DB 서버의 별도 설치가 필요하지 않습니다.
